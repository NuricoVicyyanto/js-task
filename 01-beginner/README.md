# Level 01 — Beginner — 30 Task Studi Kasus "Kopi Senja"

Folder ini berisi **30 task JavaScript dasar** yang disusun berurutan, dari variabel sampai aplikasi kasir sederhana. Setiap file adalah studi kasus mandiri dengan cerita, instruksi, ekspektasi output, kasus uji, dan checklist.

## Untuk Siapa?

- Belum pernah belajar JavaScript, atau baru mulai.
- Sedang mengambil kelas dasar/bootcamp tahap awal.
- Ingin memperkuat fondasi sebelum masuk DOM, async, dan arsitektur.

## Prasyarat

| Kebutuhan | Keterangan |
| --- | --- |
| Node.js | Versi 18+ untuk Task 01–23 dan 28–29 |
| Browser | Chrome, Edge, atau Firefox untuk Task 24–30 |
| Editor | VS Code atau editor lain |
| Dasar komputer | Bisa membuat file, membuka terminal, menjalankan perintah |

## Hasil Belajar

Setelah 30 task, siswa mampu:

1. Menulis program dengan variabel, kondisi, perulangan, dan fungsi.
2. Mengolah array dan objek, termasuk `map`, `filter`, `reduce`, dan `sort`.
3. Memvalidasi input dan menangani error sederhana.
4. Membuat halaman interaktif dengan DOM dan `localStorage`.
5. Menggunakan `fetch`, Promise, dan `async/await`.
6. Membangun aplikasi kasir sederhana dari nol.

## Cara Menggunakan

1. Baca task secara berurutan; jangan lompat.
2. Buat file kerja sesuai nama yang diminta (misalnya `task-01.js`).
3. Bandingkan output dengan bagian **Ekspektasi Output**.
4. Centang **Checklist Sebelum Kumpul**.
5. Kerjakan **Bonus** setelah bagian wajib selesai.
